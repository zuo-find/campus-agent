# 让同学不在同一个网络也能用（内网穿透）

> 解决的问题：同学用流量、在自己宿舍的 WiFi 下，也能用这个小程序。
> 做法：在你电脑上跑一个"穿透客户端"，它给你一个公网网址，把外面的请求转发到你电脑的后端。

## 先看清两件事

**第一，同学仍然要点「打开调试」。** 穿透给的是没备案的域名，微信的正式校验照样拦它。这一步只有"云托管"方案能免掉。

**第二，公网地址是公开的。** 你一旦开穿透，任何人都可能扫到这个地址并调用你的 `/chat`，**消耗的是你自己的大模型额度**。所以：
- 测试完就把穿透窗口关掉，不要 24 小时挂着
- 别在这个后端上绑你额度很高的 Key
- 想要更保险，可以让我加一道简单的访问口令（`X-App-Token` 校验），说一声就行

---

## 一、选哪个（两条免费路线，取舍很尖锐）

| | **cpolar** | **花生壳** |
|---|---|---|
| 网址固定吗 | ❌ 24 小时内随机变 | ✅ **固定二级域名**（`xxx.vicp.fun`） |
| 流量 | 不限 | **1GB/月** |
| 要实名吗 | ❌ 不用 | ✅ 要，且 HTTP 映射另需 6 元认证费 |
| 续期 | 不用 | **每 7 天手动续期一次** |
| 带宽 | 1Mbps | 1Mbps |

**建议：先用 cpolar 把今天的验证做掉，要给 20 个同学长期用再换花生壳。**

原因：cpolar 免实名、不限流量、几分钟能跑通，适合"今天就想看到效果"；但它的网址会变，对 20 个同学是灾难——每次变你都要改地址、重新上传体验版、等所有人更新。到那一步，**固定域名就是刚需**，花生壳免费版是目前唯一免费的固定域名方案。

> 如果你之后觉得"每 7 天续期 + 1GB 流量"也麻烦，那就该直接上微信云托管了——固定地址、流量够、同学还不用开调试，免费额度撑到比赛结束没问题。

## 二、cpolar 上手（约 10 分钟）

1. 打开 <https://www.cpolar.com> 注册一个账号（邮箱即可，**不需要实名**）。
2. 下载 Windows 客户端并安装。
3. 登录后进后台的 **「验证」** 页面，复制你的 **authtoken**。
4. 打开命令行（Win+R → `cmd`），执行一次（把 `<你的token>` 换掉）：

   ```
   cpolar authtoken <你的token>
   ```

5. 之后每次要开通道，就双击项目根目录的 **`穿透-启动.bat`**：

   它会先启动后端，再打开穿透，窗口里会打印类似这样的一行——

   ```
   Forwarding    https://a1b2c3d4.r2.cpolar.cn -> http://localhost:8000
   ```

   **`->` 左边那个网址就是公网地址**，把它复制下来。

6. 在小程序里 **「我的 → 服务器地址」** 粘贴这个地址，点 **「测试连接」**——出现绿条「连上了」就成功了，再点保存。

7. 把小程序重新「上传」→ 后台「选为体验版本」，同学就能在任何网络下打开了。

> **注意**：cpolar 免费版每次重启，网址都会变。变了就回到第 6 步重新填一次即可（自测阶段无所谓，给同学用就换花生壳）。

---

## 三、花生壳（要固定网址时用）

1. 注册花生壳账号并完成**实名认证**。
2. 下载客户端，在网页后台配置一条 **HTTP 映射**：
   - 内网主机：`127.0.0.1`
   - 内网端口：`8000`
   - 外网端口：`80`
3. 完成后你会拿到一个固定的 `xxx.vicp.fun` 域名，**只要不删映射，它永远不变**。
4. 把这个域名填进小程序「我的 → 服务器地址」，测试连接 → 保存。
5. **每 7 天去后台点一次续期**（免费版限制），忘了就会断。

---

## 四、换了地址之后要做什么

```
1. 小程序「我的 → 服务器地址」→ 填新地址 → 测试连接 → 保存
2. 开发者工具「上传」
3. 后台「管理 → 版本管理」→ 选为体验版本
（同学下次打开小程序会自动更新，不用重新扫码，也不用重新加体验成员）
```

## 五、可能踩到的坑

**测试连接失败**
- 穿透窗口还开着吗？关掉窗口 = 通道断 = 所有人都连不上。
- 后端的黑窗口还开着吗？**两个窗口都要在。**
- cpolar 免费版有时会给请求插一个中间提示页（浏览器打开才看得到）。如果小程序请求也被它挡住，就换花生壳。

**同学说打不开**
- 忘了点右上角 **⋯ → 打开调试**。这一步不能省。
- 你换了地址但没重新上传体验版。

**流量/额度**
- 穿透和你的大模型是两笔账。穿透免费版限速 1Mbps（不影响文字问答，图片上传会稍慢）；**真正花钱的是大模型**，同学用得越多消耗越快。

**安全**
- 穿透地址一旦泄露，别人可以直接调用你的 `/chat` 烧你的额度。
- 建议：只在需要的时候开着；测试完就关。
- 想要保险，让我加一道 `X-App-Token` 口令校验（后端检查请求头，不是这个口令直接拒绝）。小程序端我已经有"服务器地址"这个设置项，加一个口令输入框就行。
