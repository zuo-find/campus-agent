平均学分绩点
平均学分绩点（GPA）= Σ(课程绩点×课程学分) / Σ课程学分；百分制90分及以上绩点为4.0，85-89分为3.7
奖学金评定
学业奖学金按学年评定，要求当学年无不及格课程，平均学分绩点不低于3.0。
补考与重修
课程考核不合格者可参加一次补考，补考仍不合格的须重修，重修成绩标注"重修"字样。
