三步上手第一次用，先看这个
⌄
1
选一个大模型（可选） 问答页顶部那条灰色横条就是当前模型。点进去可选 DeepSeek、通义千问、智谱、Kimi、文心一言、讯飞星火、腾讯混元、豆包八家，填上你自己的 API Key 即可调用。不填也没关系，会用小程序内置的默认模型。
2
登录（想用二手/失物时要登） 到「我的」页点上方头像，或点「微信一键登录」，授权后自动带上微信头像和昵称。只问问题、算绩点的话可以不登录。
3
直接问就行 在问答页输入框里说人话即可，例如「挂科了怎么重修」「帮我写一份请假条：感冒发烧请2天」。输入框下方有四个快捷入口，点一下就能直接进入对应功能。
所有对话、成绩、发布记录都保存在你自己的手机本地，不上传服务器。

常见问题
Q点了没反应、一直转圈或提示「同步失败」⌄
多半是后端服务没启动。回到电脑上双击项目里的「启动后端.bat」，等它跑起来（窗口不要关），再回小程序重试。需要连着手机预览的话，还要把后端地址改成电脑的局域网 IP。
