# 体验版发布与测试指南

> 目标：让测试同学在自己手机上用上这个小程序，满足比赛「≥20 人测试」的要求。
> 这条路**不需要域名、不需要备案、不花钱**，今天就能做完。
> 它不能替代正式上架（正式上架要企业主体 + 算法备案，见文末）。
>
> **本方案要求同学和你的电脑连同一个 WiFi。** 想让同学用流量、在别的网络下也能用，
> 见 [《内网穿透.md》](内网穿透.md)——那一步只是换掉「服务器地址」，其余流程完全一样。

---

## 一、开工前先做这一件事（30 秒，能省掉后面全部返工）

**用手机浏览器打开下面这个地址**（手机和电脑要连同一个 WiFi）：

```
http://10.128.17.2:8000/health
```

- 看到 `{"ok":true,"docs_indexed":27}` → 通了，往下走。
- 打不开 / 转圈 → **先别上传代码**，看第七节的排障。

> 这个 IP 是启动后端时打印出来的，换 WiFi 会变。每次启动后端，黑窗口里都会显示当前地址。

---

## 二、上传体验版

1. 打开微信开发者工具，确认左下角编译无报错。
2. 点右上角 **「上传」**（不是「预览」）。
3. 版本号填 `1.0.0`，项目备注随便写（如"体验版首测"），确定。
4. 打开 [微信公众平台](https://mp.weixin.qq.com) 用管理员微信登录。
5. 左侧 **管理 → 版本管理** → 「开发版本」里能看到刚传的这版 → 点右侧 **「选为体验版本」**。
6. 页面上会出现体验版二维码，旁边可以下载保存。

---

## 三、把同学加成体验成员

**管理 → 成员管理 → 体验成员 → 添加**，输入同学的**微信号**（不是昵称）。

- 只有被加进来的人才能扫体验版二维码，否则会提示"没有权限"。
- 加进来之后，同学扫二维码 → 打开小程序 → 就能用了。
- 后面代码更新，**重新「上传」+ 再次「选为体验版本」即可**，同学下次打开会自动更新，不用重新扫码。

---

## 四、隐私保护指引（不做这步，拍照功能会直接失败）

小程序里用到了拍照和相册（拍照识别、二手市场传图），微信要求先声明才能调用。

**设置 → 服务内容声明 → 用户隐私保护指引**，勾选这两项并填写用途：

| 信息类型 | 用途怎么写 |
|---|---|
| 照片或视频信息 | 用于识别用户选择的图片（拍照识题、拍通知、拍成绩单），以及二手市场发布商品图 |
| 摄像头 | 用于拍摄需要识别的题目、通知、成绩单 |

提交后要等审核（通常几小时）。

**如果体验版拍照时报 `api scope is not declared in the privacy agreement`**，说明指引还没生效。这种情况可以临时在 `miniprogram/app.json` 里加一行跳过检测（仅对开发版/体验版有效，正式发布必须靠上面的指引，不能靠这个）：

```json
"__usePrivacyCheck__": false,
```

## 五、发给测试同学的话（可直接复制转发）

> **「校园助手」体验版试用说明**
>
> 1. 用微信扫我发的二维码，会提示打开体验版小程序，点「允许」。
> 2. 打开后点右上角 **⋯** → **打开调试**（这一步必须做，否则连不上服务器）。
> 3. 出现绿色小字「vConsole」就说明成功了。可以点掉它，不影响使用。
> 4. **当前版本必须连校园网**（和我电脑同一个 WiFi），用流量打不开。（等我把穿透配好会另外通知你，那时候就不用了）
> 5. 可以试的功能：
>    - 「问答」页问校园制度，例如"挂科了怎么重修"
>    - 输入框左边有个相机按钮，可以拍题、拍通知转待办、拍成绩单导入
>    - 「成绩」页录入学分分数看绩点
>    - 「生活」页有二手市场、失物招领
> 6. 用的时候遇到任何问题（打不开、报错、答得不对），截图发我，谢谢！

## 六、他们最容易卡住的地方

按出现概率排序：

1. **忘了点「打开调试」** —— 会一直转圈或提示"连不上后端"。这是第一名。
2. **用了手机流量** —— 当前方案必须是同一个 WiFi。想免掉这条就配内网穿透（见 [《内网穿透.md》](内网穿透.md)）。
3. **我这边后端窗口关了** —— 那个黑窗口一关，所有人的都连不上。
4. **我换了 WiFi，IP 变了** —— 需要通知同学…… 不，不用：**你在「我的 → 服务器地址」里改一次，重新上传体验版，同学重新打开就自动更新了。**
5. **拍照报隐私错误** —— 见第四节。

## 七、排障

**手机浏览器打不开 `http://10.128.17.2:8000/health`**

按顺序查：

1. 后端黑窗口还开着吗？
2. 手机和电脑是同一个 WiFi 吗？
3. **Windows 防火墙**：第一次启动后端时系统会弹窗问"是否允许访问网络"，点了「取消」就会一直被拦。重新允许的方法：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 Python → 勾上「专用」。
   或者用**管理员身份**打开 PowerShell/CMD 执行一次：
   ```
   netsh advfirewall firewall add rule name="campus-agent" dir=in action=allow protocol=TCP localport=8000
   ```
4. **校园网的客户端隔离**（重点）：很多学校 WiFi 开了「AP 隔离」，同一 WiFi 下的设备之间也不能互访。判断方法：让同学用手机 ping 你的电脑，或换个环境试（比如电脑连手机热点）。
   **绕过办法**：**用手机开个人热点，让电脑连这个热点**。这样电脑和手机在同一个热点子网里，一定能互通。连上后重启后端，黑窗口会打印新的 IP（通常是 `192.168.x.x` 段），把这个新地址填进小程序的「服务器地址」，重新上传体验版即可。

## 八、这一步之后是什么

体验版能满足比赛的 20 人测试，但**它不是"发布"**：别人搜不到、扫码要验权限、还必须开着你的电脑。

真正对外发布要过三道关，都卡在资质上：

1. **域名 ICP 备案** —— 小程序请求必须走 HTTPS + 已备案域名，不能用 IP。备案 7~20 个工作日。
2. **小程序备案** —— 2023 年 9 月起强制。
3. **深度合成类目 + 算法备案** —— AI 问答功能需要，**类目只开放给企业主体**，个人主体申请不了；算法备案周期以月计。

所以**在比赛截止前，正式上架不可行**（不是技术问题）。如果之后要做，建议按这个顺序：先确认主体能不能转成学校/企业 → 买域名备案 → 再走类目和算法备案。

## 附：每次改动后的固定动作

```
后端代码改了     → 关掉黑窗口，重新双击「启动后端.bat」
小程序代码改了   → 开发者工具「上传」→ 后台「选为体验版本」
换 WiFi 了       → 看黑窗口打印的新 IP → 小程序「我的 → 服务器地址」改掉 → 重新上传
```
